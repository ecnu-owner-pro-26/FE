确保 wx.login 获取的 code 仅被使用一次，且没有因异步逻辑导致 code 过期。

在网络请求前后增加完整的日志打印（console.log），清晰输出准备发送的 code 以及接收到的完整网络响应体。"

# my rules
1. 代码内所有注释不得口语化、对话式，必须客观描述代码片段内容
2. 变量名命名风格与后端统一，json等格式与后端一致
3. 不得修改后端代码
4. 不得在小程序中输出除错误码外的面向程序员的文字
